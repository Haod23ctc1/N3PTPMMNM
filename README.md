# N3PTPMMNM - Website Bán Nội Thất

## 1. Giới thiệu dự án

N3PTPMMNM là dự án website bán nội thất, hỗ trợ người dùng tìm kiếm và xem thông tin sản phẩm nội thất trực tuyến.

Dự án được thực hiện nhằm rèn luyện kỹ năng phát triển phần mềm, làm việc nhóm và quản lý mã nguồn bằng Git, GitHub.

## 2. Mục tiêu

- Xây dựng website giới thiệu sản phẩm nội thất.
- Hỗ trợ người dùng tìm kiếm và xem thông tin sản phẩm.
- Thực hành quy trình làm việc nhóm bằng Git và GitHub.
- Sử dụng branch, commit, push và pull request.

## 3. Chức năng

- Hiển thị danh sách sản phẩm nội thất.
- Xem thông tin chi tiết sản phẩm.
- Tìm kiếm và phân loại sản phẩm.
- Quản lý thông tin sản phẩm.
- Các chức năng mua hàng và quản lý đơn hàng nếu được triển khai.

## 4. Công nghệ

Công nghệ sử dụng sẽ được cập nhật dựa trên mã nguồn thực tế của dự án.

- Quản lý mã nguồn: Git và GitHub.
- Công cụ phát triển: Visual Studio hoặc Visual Studio Code.
- Ngôn ngữ, framework và cơ sở dữ liệu: theo cấu hình thực tế của dự án.

## 5. Cài đặt dự án

Clone repository:

```bash
git clone https://github.com/Tuyen-CyberCode/N3PTPMMNM.git
```

Di chuyển vào thư mục dự án:

```bash
cd N3PTPMMNM
```

Mở dự án bằng công cụ phát triển phù hợp, cài đặt các thành phần cần thiết và chạy theo cấu hình của dự án.

## 6. Quy trình đóng góp

1. Clone repository về máy.
2. Tạo branch riêng cho công việc.
3. Thực hiện thay đổi mã nguồn.
4. Kiểm tra các thay đổi.
5. Commit những file cần thiết.
6. Push branch lên GitHub.
7. Tạo Pull Request để đề xuất hợp nhất vào branch `main`.
8. Chờ review và phản hồi từ người quản lý dự án.

Xem hướng dẫn chi tiết tại [CONTRIBUTING.md](CONTRIBUTING.md).

## 7. Thành viên

Danh sách thành viên và vai trò sẽ được cập nhật theo thông tin chính thức của nhóm.

## 8. Giấy phép

Giấy phép của dự án sẽ được bổ sung theo quy định của repository.
